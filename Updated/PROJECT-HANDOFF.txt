6. USING THE SOURCE ON ANOTHER COMPUTER
Open Updated as the project folder. Install Node.js 20 or newer, then run npm ci.
Copy .env.example to .env and configure the deployed URL and credentials locally. Saved sessions and real credentials are excluded.
Run npm run typecheck to check TypeScript. npm run batches:list lists batches without launching application tests.
Use the batch runner with an explicit profile and batch when further execution is authorized. Do not launch all tests by default.
Approval and other data-changing tests require intentionally configured target records and settings.
