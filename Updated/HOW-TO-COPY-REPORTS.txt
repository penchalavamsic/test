HOW TO COPY LIMAS REPORTS TO ANOTHER LAPTOP

You do NOT need the entire test-runs folder just to review reports.

1. ONE BATCH
Copy that completed run's Test-Reports/Complete-Suite-Test-Report.zip.
On the other laptop, extract the entire ZIP into a folder.
Open the extracted index.html in Chrome or Edge.
Keep index.html, Evidence, and all other extracted contents together.
This includes the screenshots, video recordings, test steps, expected results and recorded outcomes captured for that run. A trace file is included when one was captured.
The ZIP is self-contained for that run: the original source project and original computer folder are not required to read the HTML evidence report.
IMPORTANT: Complete-Suite means that particular batch/run. It does not automatically include all batches in the tab.

2. THE WHOLE SYSTEM USER DASHBOARD
Recommended existing folder:
test-runs/super-admin-live-20261125/delivery/dashboard-20261125T180433/
Copy this entire folder and all its subfolders, then open its index.html.
It contains the combined Dashboard case index and the included execution attempts.
Keep the r folder and every other supplied folder/file with index.html.
The separate large Dashboard ZIP was removed to save disk space; the complete extracted review folder is still available.
Validation already completed: 51,806 local links checked. A relocated sample loaded all 94 screenshots and 22 videos.

3. ANOTHER TAB
You may copy that tab's completed Complete-Suite-Test-Report.zip files, one per batch/run you want to review.
Keep each ZIP in a distinct batch/run folder because the filenames repeat.
Extract each ZIP separately and open the relevant index.html.
You may alternatively copy the entire tab folder, but it includes extra raw artifacts and duplicate report formats and is much larger.
A single combined, fully validated delivery folder has not yet been finalized for every other tab.

4. ONE TEST CASE
Copy its Individual-Test-Reports/<test-id>_test-report.zip and extract it completely.
It contains only that test's available evidence.

5. AVOID BROKEN SCREENSHOTS
Do not copy index.html by itself.
Do not open index.html from inside the ZIP preview: extract first.
Do not move, rename, or delete individual Evidence/r subfolders after extracting.
Keep the relative structure unchanged. The destination drive letter and parent folder can be different.
Normal copying or creating a ZIP preserves the contents of files that share disk storage locally.
